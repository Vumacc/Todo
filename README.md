# About Todo
A generic To-Do list application. Made with C#.

# Features
- Add, delete, edit, and move entries.
- Three separate lists (To-Do, Doing, Finished) for organisation.
- Set urgency of entries.
- idk man there's not much

# Installation
Prebuilt binaries for Windows and Linux can be downloaded from the [Releases](https://github.com/Vumacc/Todo/releases) tab. <br>
Both builds need to be run using the terminal.

You can compile it yourself if you want to.
```
> git clone https://github.com/Vumacc/Todo.git
> cd Todo
> dotnet build
```
